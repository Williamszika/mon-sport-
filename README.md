# Mon Sport & Mon Soin

Mes documents personnels de suivi — le programme d'entraînement (FitX Aachen), le
rituel de soin visage & corps (Balea / dm), et le journal qui retrace tout.

Ce sont des pages HTML autonomes : il suffit d'ouvrir un fichier dans un
navigateur. Elles sont aussi prévues pour l'impression (mise en page dédiée,
couleurs conservées).

**Point d'entrée : [`index.html`](index.html)** — le sommaire qui relie tout.

| Fichier | À quoi ça sert |

## L'essentiel, en bref

**Sport** — 3 séances par semaine, en alternant A / B / A avec un jour de repos
entre deux. 12–15 répétitions à poids modéré (ça dessine sans épaissir), du
cardio à chaque séance. Séance découverte faite le **lundi 10 août 2026** ; le
suivi structuré démarre le **lundi 17 août**.

**Soin** — Vitamine C le matin, rétinol les mardis et vendredis, Aloe les autres
soirs, peeling le dimanche. SPF tous les jours, non négociable. Gommage corps
mercredi et dimanche.

**Kegels** — tous les jours. 🔁

## Tenir le journal à jour

Après chaque séance, noter dans `sport/journal-progression.html` la durée du
cardio et le poids utilisé sur chaque machine — c'est ce qui permet de savoir
quand monter d'un cran. Et compléter `JOURNAL.md` / `journal.html` quand quelque
chose change dans le programme ou dans la routine.
